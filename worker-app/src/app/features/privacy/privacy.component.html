# 1. qué datos recopilamos

Para ofrecerte el servicio de búsqueda de empleo asistida por IA, recopilamos los datos que tú nos proporcionas: nombre, email, contraseña (almacenada de forma segura y encriptada), tu hoja de vida (PDF), perfil profesional, skills, ubicación, salario deseado y configuración de búsqueda (keywords, portales, modelo de IA).

# 2. cómo usamos tus datos

Tus datos se utilizan exclusivamente para: (a) autenticarte en la aplicación, (b) buscar y filtrar vacantes de empleo en portales públicos de acuerdo a tu perfil, (c) calcular el porcentaje de compatibilidad (match) entre tu perfil y las vacantes, y (d) enviarte avisos por WhatsApp si activas esa opción con tu número y clave CallMeBot.

# 3. inteligencia artificial

La lectura y análisis de tu hoja de vida, así como el match con vacantes, se realiza mediante proveedores de IA externos (Groq). Tu CV se envía únicamente para ese análisis y no se comparte con fines comerciales ni se vende a terceros.

# 4. cookies y almacenamiento local

Usamos almacenamiento local del navegador (localStorage) para mantener tu sesión iniciada y recordar tus preferencias (incluida tu elección sobre cookies). No usamos cookies de rastreo ni publicidad de terceros.

# 5. retención y eliminación

Tus datos permanecen en la base de datos mientras tu cuenta esté activa. Puedes eliminar tus datos en cualquier momento contactando al desarrollador; también puedes cerrar sesión y borrar los datos locales desde tu navegador.

# 6. seguridad

Las contraseñas se almacenan con hash (bcrypt), las comunicaciones con el servidor se realizan sobre HTTPS y el acceso a los datos está protegido por tokens JWT por usuario.

# 7. tus derechos

Tienes derecho a acceder, corregir o eliminar tus datos personales. Para ejercer estos derechos, contáctanos en la sección de contacto de esta página.
